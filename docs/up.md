本服为**共建服**，欢迎每位小伙伴共同维护与丰富影视库。

当获得观影资格，并在 [emos 官网](https://emos.best) 阅读并同意《上传协议》后，即可开始上传资源。

:::tip[关于上传奖励]
目前上传一集资源（无论文件大小）固定奖励 **1 萝卜**, 后续可能会调整   
上传并非快速赚取萝卜的捷径，但当你在播放列表中看到其他人正在观看你分享的影片时，那份成就感与快乐是无可替代的 ✨
:::

##  上传规范

为了保证大家的观影体验与媒体库质量，请务必遵守以下规则：

- 严禁上传带有任何形式广告的视频（包括内嵌字幕广告、音频广告等）。上传前可以检查一遍
- 严禁上传低码率、画质劣化严重的资源（年代久远的老片除外）。
- 请勿上传与现有库内版本相同或码率相近的重复资源。
- 禁止上传任何 18+、猎奇或违规内容。

##  上传方式

### 方式一：网页上传

可以通过以下网页进行上传：

- [emos.club](https://emos.club/upload)
- [emya.wwzb.de](https://emya.wwzb.de/upload)

:::info[命名规范（重要）]
为了方便系统自动精准识别刮削，上传前建议将视频文件重命名为以下格式：  
`影片名称.S01E01{tmdbid=xxxx}.mkv`  
*(例如：`七王国的骑士S01E01{tmdbid=224372}.mkv`)*
:::

如果未成功识别,请自行搜索对应的剧集,在视频页进行上传

> **提示**：目前存储于 Cloudflare R2，建议**开启代理节点（挂梯）**上传以获得最佳的速度与稳定性。

---

### 方式二：脚本 / 面板 / VPS 自动化上传

社区小伙伴开发了以下工具，适合进阶用户批量处理与自动化同步：

- [liyk-master/auto_rename](https://github.com/liyk-master/auto_rename) 
- [somebyteorg/emos_video_upload](https://github.com/somebyteorg/emos_video_upload) 

*此类工具需要一定的 Linux / 脚本基础，请参考各自仓库的 README 自行探索研究。*

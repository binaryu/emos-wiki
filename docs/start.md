# 观影指南

获取观影资格后，可以通过以下方式获取线路并配置 Emby 客户端观影。

---

## 如何获得观影权限？

- **活跃参与**：群内会不定期开放活动或随缘掉落资格，多在 Telegram 群内友善交流。
- **好友邀请**：如果你有已在服内的朋友，将你的专属用户 ID（`e...s`）发给他，由他邀请你。
- **商城购买** :下面介绍的网站都有商城页面,可以在里面使用萝卜购买邀请资格

---

## Emby密码
默认获得的是三位数的随机密码,具有时效性

当达到 [筑基](https://emos.dpdns.org/carrot) 境界(100萝卜) 即可自动解锁固定密码, 可前往上面的网站设置固定密码


## 推荐客户端

复制线路地址,端口,账号,密码，填入你的 Emby 客户端即可开始观影：

| 平台  | 推荐客户端 |
| :--- | :--- | 
|  **Windows** | `Hills`、`RodelPlayer` |
|  **Android** | `Hills`、`Yamby` | 
|  **Android TV** | `Yamby`、`Chaichai`、`Afusekt` | 
|  **iOS** | `SenPlayer`、`Lenna`、`Eplayer X` |
:::warning[ 注意事项]
本服后端为**自研架构**，不同客户端可能会存在兼容性差异。如遇到特定客户端无法正常加载或串流中断，建议优先**更换上述表格中的其他推荐软件**，或联系客户端开发者进行适配。

本服没有黑白名单,只有适配与不适配
:::
